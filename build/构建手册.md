# 构建手册

> 目标：让读者在一台**全新的机器**上，按本手册从源码构建出可运行的产物。


## 1. 环境依赖

| 依赖 | 版本 | 获取方式 |
| --- | --- | --- |
| JDK | 17 | https://adoptium.net/ |
| Maven | 3.9.x | https://maven.apache.org/ |
| Docker（可选，用于镜像） | 24+ | https://www.docker.com/ |
| MySQL | — | 不需要，本项目使用 H2 文件库 |

验证：`java -version`、`mvn -version`、`docker -version`

## 2. 获取源码

```bash
git clone https://github.com/xych5q/online-shop.git
cd online-shop
git checkout v0.1-iter1      # 按验收 tag 切换
```

## 3. 构建步骤（源码 → 二进制）

```bash
# 1) 清理
mvn clean
# 2) 编译
mvn compile
# 3) 跑单元测试
mvn test
# 4) 打包（产出 target/*.jar）
cd server && mvn package -DskipTests=false
# 一键：
bash build/build.sh
```

产物：`server/target/online-shop.jar`

## 4. 每一步发生了什么（讲清楚，验收会问）

1. `clean` 删除 `target/`，保证没有历史残留。
2. `compile` 把 `src/main/java` 编译为 `target/classes` 下的 `.class`。
3. `test` 执行 `src/test/java` 的 JUnit 用例，失败则构建中断。
4. `package` 把 class + 资源 + 依赖打成可执行 jar。
5. 依赖由 `pom.xml` 声明，Maven 从本地仓库/中央仓库解析，**不需要手动拷 jar**。

## 5. 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 依赖下载超时 | 默认中央仓库慢 | 配置阿里云镜像 `~/.m2/settings.xml` |
| 测试用例失败 | 代码/环境问题 | 看 `target/surefire-reports/` |
| 找不到主类 | 未配 shade 插件 | 检查 `pom.xml` 打包插件 |
