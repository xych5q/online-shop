## 0. 测试环境与前置

| 项 | 取值 |
| --- | --- |
| JDK | 21（Temurin） |
| 构建 | Apache Maven 3.9 |
| 框架 | Spring Boot 3.3.4 + JUnit 5 + Spring Test MockMvc |
| 数据库 | H2 文件库（`server/data/`，测试前自动 `deleteAll` 清理） |
| 卖家账号 | `admin` / `seller123`（`application.yml` 的 `app.seller.*`，首次启动由 `DataInitializer` 创建） |
| 服务地址 | 默认 `http://localhost:8080`；本文冒烟脚本用 `8090` 避免与开发实例冲突 |

**三条执行命令**：

```bash
# 1) 自动化测试（18 组 JUnit，含构建）
cd server && mvn -B clean package

# 2) 接口冒烟（需先起服务）
cd server && java -jar target/online-shop.jar --server.port=8090
cd ../../test-cases && BASE=http://localhost:8090 bash api-smoke.sh

# 3) UI 端到端（浏览器手工，见第三节；Selenium 版为迭代 2 项）
```

**数据清理约定**：每个自动化用例执行前 `@BeforeEach cleanUp()` 清空 `intent` 与 `product` 两张表（`seller` 账号表不动），因此**用例之间互不依赖，可任意顺序单独运行**。手工用例执行前请删除 `server/data/` 目录后重启服务，保证从一个干净状态开始。
