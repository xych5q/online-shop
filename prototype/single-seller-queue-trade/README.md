# 单卖家排队交易系统

依据《版本需求总结.md》实现的单卖家、单件在售、先到先得排队、线下成交的交易系统。零依赖，仅需 Node.js 运行。

## 启动

```bash
node server.js
# 或 npm start
```

- 买家页：http://localhost:3000/
- 卖家后台：http://localhost:3000/admin
- 默认卖家账号：`admin` / `seller123`（登录后请及时修改密码）

数据持久化在 `data/db.json`，商品图片存于 `data/uploads/`，重启不丢失。

## 已实现规则（对应需求文档）

- 买家免注册，提交意向（姓名 + 电话必填）即入队，口令码仅提交成功页展示一次
- 凭口令码：查位次 / 是否进入交易、修改姓名电话、撤销意向
- 单件在售；发布后商品信息不可修改；需下架后才能发布下一件
- 商品状态机：在售 / 已冻结（手动·自动）/ 已下架
- 与队首进入交易 → 自动冻结；交易成功 → 直接下架进历史；交易失败 → 自动递补下一位（队列空则恢复在售）
- 失败买家由卖家确认「作废」或「重新排队」（重新排队 = 队尾 + 时间刷新，口令码不变）
- 交易成功时队列剩余意向自动转失败；终态三类：成功 / 撤销 / 失败
- 手动冻结/解冻（仅可解冻手动冻结的商品）；手动下架
- 历史档案只读，展示发布时间 / 交易时间 / 意向流水（口令码不进历史、卖家后台全程不显示口令码）
- 修改密码需验证原密码，新密码 ≥ 8 位
- 图片：选填 1 张，JPG/PNG，≤5MB；价格必填 >0，两位小数

## 设计决策（需求开放点的处理）

| 开放点 | 本实现取值 |
|--------|-----------|
| 商品名称/描述长度 | 名称 ≤100 字，描述 ≤2000 字 |
| 口令码格式 | 8 位大写字母数字（去除易混淆字符），全库唯一 |
| 无图占位 | 内置 SVG 占位图 |
| 历史分页 | 每页 10 件 |
| 进入交易二次确认 | 有（confirm 弹窗）；标记成功/失败、下架、冻结、撤销同样有确认 |
| 处于交易中的买家撤销 | 禁止自行撤销，提示联系卖家 |
