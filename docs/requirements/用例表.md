## 二、核心用例详表

### UC-03 发布商品

| 项 | 内容 |
| --- | --- |
| 参与者 | 卖家 |
| 前置条件 | 已登录后台；当前无"在售/冻结"商品 |
| 主流程 | 1. 卖家填写名称、描述、价格，可选上传图片<br>2. 系统校验：名称非空 ≤100 字、描述 ≤2000 字、价格 >0 两位小数、图片 JPG/PNG ≤5MB<br>3. 系统保存商品，状态置"在售"<br>4. 买家端立即可见 |
| 扩展流程 | 2a. 校验失败 → 提示对应错误，返回表单<br>1a. 已有在售/冻结商品 → 提示"已有商品在售或交易中，需先下架" |
| 后置条件 | 商品"在售"；商品信息此后不可修改 |

### UC-12 提交购买意向

| 项 | 内容 |
| --- | --- |
| 参与者 | 买家 |
| 前置条件 | 商品状态为"在售" |
| 主流程 | 1. 买家填写姓名、电话，提交<br>2. 系统校验必填（**姓名电话完全不校验格式**，2026-10-07 拍板，填错责任在买家）<br>3. 系统生成唯一口令码，意向入队（按提交时间计位次）<br>4. 页面展示口令码，**仅此一次**，附"请截图保存"提示 |
| 扩展流程 | 1a. 商品无/冻结中 → 提示"暂无商品在售"或"商品交易中，暂停接收新意向"<br>2a. 姓名或电话为空 → 提示"姓名与联系电话均为必填"<br>3a. 同一人重复提交 → 不去重，作为独立意向 |
| 后置条件 | 意向"排队中"；买家持口令码 |

### UC-06 队首自动进入交易

| 项 | 内容 |
| --- | --- |
| 参与者 | 系统（**自动**；卖家后台无"进入交易"操作，2026-10-07 拍板） |
| 前置条件 | 商品"在售"；队列非空 |
| 主流程 | 1. 买家提交意向入队后，系统检测队首，**自动触发**进入交易<br>2. 系统取队列首位（按提交时间，不可挑人）<br>3. 该意向置"交易中"；商品同时自动置"冻结" |
| 扩展流程 | 1a. 队列为空 → 不触发，商品保持"在售" |
| 后置条件 | 商品"冻结"，不再接收新意向；队首买家凭码可查到"已进入交易" |

### UC-07 标记交易结果

| 项 | 内容 |
| --- | --- |
| 参与者 | 卖家 |
| 前置条件 | 商品"冻结"且处于交易中 |
| 主流程（成功） | 1. 卖家选"交易成功"并确认<br>2. 当前意向 → 成功；队列剩余全部 → 失败<br>3. 商品 → 已下架进入历史；全部口令码失效 |
| 主流程（失败） | 1. 卖家选"交易失败"并确认<br>2. 当前意向 → 失败（待处置）<br>3. 队列有人 → 下一位自动递补进入交易；队列空 → 商品恢复在售 |
| 扩展流程 | 1a. 标记成功后不可撤销 |
| 后置条件 | 见主流程；历史与意向流水同步更新 |

### UC-15 凭口令码撤销意向

| 项 | 内容 |
| --- | --- |
| 参与者 | 买家 |
| 前置条件 | 持有效口令码；意向未处终态（**排队中、交易中均可撤销**，2026-10-07 拍板） |
| 主流程 | 1. 买家凭码发起撤销并确认<br>2. 系统将意向置"已撤销"（终态，历史留痕）<br>3. 口令码失效 |
| 扩展流程 | 1a. **队首（交易中）撤销** → 交易终止、商品自动恢复在售、后续队列按序递补；下一位队首自动进入交易<br>1b. 排队中撤销 → 仅队列少一人，后续位次前移<br>1c. 撤销按钮**无需隐藏**（不存在"进入交易后不能撤"） |
| 后置条件 | 意向"已撤销"；口令码失效 |

### UC-08 处置失败买家

| 项 | 内容 |
| --- | --- |
| 参与者 | 卖家 |
| 前置条件 | 存在"失败"且未处置的意向 |
| 主流程（作废） | 卖家选"作废"→ 意向彻底结束 |
| 主流程（重新排队） | 卖家选"重新排队"→ 新排队记录生成：排到队尾、提交时间刷新、**口令码不变**；**重排无次数上限**（2026-10-07 拍板，且由卖家逐单确认、非系统自动入队） |
| 扩展流程 | 商品已下架 → 无法处置 |
| 后置条件 | 原意向标记已处置 |
