# 收藏模块 · RESTful API 接口设计文档

> 模块：买家收藏（L3-5）　|　版本：v1.0 · 2026-11-18　|　范围：迭代 3（挑战需求 B）
> 需求依据：B.2.1-4 / B.2.1-5 / B.2.1-6、B.2.4-1 / B.2.4-3；实体注释引用的 FR-D9 / FR-D11 / G15 同口径。
> 交接：字段清单 → 嵇宇锋（J3-1 收藏页）；转收藏内部契约 → 董嘉润（购物车域）。

## 一、通用约定

**1. 接口前缀**：所有接口以 `/api/favorites` 开头（买家侧）。

**2. 鉴权**：全部接口需买家登录态 token：

```
X-Token: <登录返回的 token>
或
Authorization: Bearer <token>
```

未携带或无效 → `401 {"error":"未登录或登录已失效"}`。

**3. 返回格式**：

| 场景 | HTTP | 响应体 |
|---|---|---|
| 成功 | 200 | `{"ok":true, ...}` |
| 参数/业务校验失败 | 400 | `{"error":"中文文案"}` |
| 未登录 | 401 | `{"error":"未登录或登录已失效"}` |
| 商品不存在 | 404 | `{"error":"商品不存在"}` |

**4. 收藏商品的状态口径**（迭代 3 两态，见 L3-1）：

| status | offShelfReason | 含义 | 前端表现 |
|---|---|---|---|
| `on_sale` | `null` | 在售 | 正常展示，可点进详情 |
| `off_shelf` | `MANUAL` | 卖家手动下架 | 标注「已下架」并置灰 |
| `off_shelf` | `SOLD_OUT` | 售罄自动下架 | 标注「无货」并置灰 |

> 展示口径（B.2.1-4）：收藏列表只展示**商品名称、价格、主图**，点击只能进商品详情；
> **不提供从收藏直接下单或加购物车的入口**；列表**不含库存与销量**（B.2.1-5）。

## 二、接口明细

### 1. 我的收藏列表（分页）

| 项 | 内容 |
|---|---|
| **URL** | `GET /api/favorites?page=1&size=10` |
| **Method** | GET |
| **鉴权** | 是 |

**查询参数：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `page` | int | 否 | 从 1 起，默认 1；越界取最后一页 |
| `size` | int | 否 | 每页条数，默认 **10**，上限 **100** |

> 分页口径说明：需求未规定收藏分页；P5 组会裁定收藏属授权自定，组内统一为 10 条/页（与订单/历史一致）。

**排序**：按收藏时间（`favoritedAt`）倒序；同一时间按收藏记录 id 倒序兜底。

**成功返回（200）：**

```json
{
  "ok": true,
  "page": 1,
  "pageSize": 10,
  "totalPages": 2,
  "total": 12,
  "items": [
    {
      "productId": 5,
      "name": "机械键盘",
      "price": 199.00,
      "imageUrl": "/uploads/kb.png",
      "status": "off_shelf",
      "offShelfReason": "SOLD_OUT",
      "available": false,
      "favoritedAt": "2026-11-18T15:00:00"
    }
  ]
}
```

**字段说明：**

| 字段 | 类型 | 说明 |
|---|---|---|
| `productId` | long | 商品 id（取消收藏时直接用） |
| `name` | string | 商品名称（当前值，不做快照） |
| `price` | decimal | 商品当前价格 |
| `imageUrl` | string/null | 主图（sortOrder 最小的一张；无图回退旧单图字段；都没有为 null，前端显示占位图） |
| `status` | string | `on_sale` / `off_shelf` |
| `offShelfReason` | string/null | `SOLD_OUT` 售罄 / `MANUAL` 手动下架 / 在售为 null |
| `available` | boolean | 是否可购买（仅 `on_sale` 为 true），供前端按钮置灰 |
| `favoritedAt` | datetime | 收藏时间 |

**行为规则：**
- 只返回当前登录账号的收藏（按账号存储、账号间隔离）；
- 已下架 / 售罄商品**保留在列表中并标注，不自动消失**（B.2.1-6）；
- 空列表返回 `total=0、items=[]`。

### 2. 收藏商品

| 项 | 内容 |
|---|---|
| **URL** | `POST /api/favorites` |
| **Method** | POST |
| **鉴权** | 是 |

**请求体：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `productId` | long | 是 | 商品 id |

```json
{ "productId": 5 }
```

**校验规则：**
- `productId` 缺失 → `400 {"error":"请选择要收藏的商品"}`
- 商品不存在 → `404 {"error":"商品不存在"}`
- **同一账号已收藏** → 直接返回成功，不重复插入、不报错（G15 去重）

**成功返回（200）：**

```json
{ "ok": true }
```

---

### 3. 取消收藏

| 项 | 内容 |
|---|---|
| **URL** | `DELETE /api/favorites/{productId}` |
| **Method** | DELETE |
| **鉴权** | 是 |

**路径参数：** `productId`（long）

**行为规则：**
- 只删除当前登录账号自己的收藏记录；
- **幂等**：未收藏时同样返回成功，方便前端重复点击。

**成功返回（200）：**

```json
{ "ok": true }
```

## 三、购物车「批量转收藏」内部契约（B.2.4 / FR-D11）

> 归属：购物车域负责人 **董嘉润**；本模块只提供写入方法，转收藏的入口与购物车移除在购物车侧。

**方法：**

```java
boolean FavoriteService.addForBuyer(Long buyerId, Long productId)
```

**规则：**
- 按 `buyerId` 幂等收藏，不经过 token；
- 首次收藏返回 `true`；已收藏**静默去重返回 `false`**，不报错（B.2.4-3）；
- `productId` 为空 → 400「请选择要收藏的商品」；商品不存在 → 404「商品不存在」。

**调用链（B.2.4-1「转」= 转移，两边不都留）：**

```
购物车勾选多条
  → 逐条调用 addForBuyer(buyerId, productId)
  → 全部成功后，把对应条目移出购物车
```

> 建议购物车域在同一事务内完成「加收藏 + 删购物车条目」；本方法只负责收藏写入，不控制调用方事务。

## 四、错误码汇总

| HTTP | error 文案 | 场景 |
|---|---|---|
| 401 | 未登录或登录已失效 | 未带 / 无效 token |
| 400 | 请选择要收藏的商品 | 缺少 productId |
| 404 | 商品不存在 | productId 对应商品不存在 |

## 五、需求编号对照

| 需求 | 落地位置 |
|---|---|
| B.2.1-4 列表只展示名称/价格/主图，无下单/加购入口 | 列表字段与前端约定（本章第一、二节） |
| B.2.1-5 不要库存、销量 | 列表不返回 stock / sales 字段 |
| B.2.1-6 下架/售罄保留并标注、不自动消失 | `status` + `offShelfReason` + `available` |
| B.2.4-1 转收藏 = 转移 | `addForBuyer` + 调用方移除购物车条目 |
| B.2.4-3 已收藏静默去重 | `addForBuyer` 返回 false、不报错 |
| FR-D9 / G15 / FR-D11 | 实体注释与上述口径一致（按账号、去重、独立列表） |
