# 部署手册

## 方式一：Docker 镜像（推荐，课程标准动作）

```bash
# 1) 构建镜像
docker build -f deploy/Dockerfile -t online-shop:0.1 .

# 2) 启动容器
docker run -d --name shop -p 8080:8080 online-shop:0.1

# 3) 验证
curl http://localhost:8080/health
# 浏览器打开 http://localhost:8080

# 4) 导出镜像（作为验收材料交付）
docker save online-shop:0.1 -o online-shop-0.1.tar
```

## 方式二：直接运行 jar

```bash
java -jar target/online-shop-0.1.jar --spring.profiles.active=prod
```

## 环境要求与配置项

| 配置项 | 说明 | 默认值 |
| --- | --- | --- |
| 端口 | 服务监听端口 | 8080 |
| 数据库地址 | MySQL 连接串 | 见 `application.yml`，敏感值走环境变量，**不入库** |
| 文件上传目录 | 商品图片等 | `/data/upload` |

## 回滚

```bash
docker stop shop && docker rm shop
docker run -d --name shop -p 8080:8080 online-shop:<上一个版本 tag>
```
